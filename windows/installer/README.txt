语境输入法 - 边写边翻译的智能输入法

【功能特点】
- 边写边翻译：打字的同时实时翻译，无需切换应用
- 语境翻译（免费）：基于微软 Edge 翻译接口，无需 API Key
- 大模型翻译：支持 DeepSeek、GLM、Qwen、Kimi、OpenAI 等多种大模型
- 流式输出：大模型翻译实时显示，降低首字延迟
- 多语言支持：英文、中文、日文、韩文、法文、德文、西班牙文等 23 种语言
- 悬浮窗：可自定义位置、大小、颜色、透明度
- 快捷复制：Ctrl+Alt+逗号 快速复制翻译内容

【安装说明】
1. 运行安装程序，按提示完成安装
2. 打开「系统设置 > 时间和语言 > 语言和区域」
3. 在「首选语言」中找到「中文（简体）」
4. 点击「语言选项」，在「键盘」中添加「语境输入法」
5. 使用 Win+Space 切换到语境输入法即可开始使用

【快捷键】
- Win+Space：切换输入法
- Shift：中英文切换
- Ctrl+Alt+逗号：复制翻译内容
- 1-9 数字键：选择候选词
- 空格：确认候选词
- 方向键：导航候选词
