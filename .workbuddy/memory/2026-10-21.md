# 2026-10-21

## 卸载工具（macOS / Windows）

- 新增 `macos/scripts/uninstall.sh`（唯一清理逻辑），`macos/Uninstaller` SwiftUI 外壳，`macos/scripts/package-uninstaller.sh`。
- Windows 新增 `installer/cleanup.nsh` 共享宏、`installer/uninstaller.nsi` 独立卸载器、`scripts/build-uninstaller.bat`；`installer.nsi` 卸载区段改为复用宏。
- 修复首次扫描被 `isBusy` 初始状态拦截、导致界面卡在扫描页的问题。
- 修复命令行“半卸载”：有 `/Library/Input Methods` 安装时先 `sudo` 清理系统目录，失败或取消授权即中止，不再先删词库；`--system-only` 删除失败返回非 0，GUI 据此中止。
- 发布形态调整：macOS 只出一个 `语境输入法-<版本>.dmg`，内含「语境输入法安装器.app」与「语境输入法卸载工具.app」；CI 与 README 已同步。Windows 安装包内置同一套卸载逻辑，独立卸载器只用于安装损坏场景。
